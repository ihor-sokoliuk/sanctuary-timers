# PT Serif

Unmodified PT Serif regular and bold, copyright 2010 ParaType Ltd., distributed under the SIL Open Font License 1.1 in `OFL.txt`.

Source: [Google Fonts repository](https://github.com/google/fonts/tree/80327115aa6e63ea8947558e5fb676f5287878ba/ofl/ptserif), revision `80327115aa6e63ea8947558e5fb676f5287878ba`.

The executable embeds the two font files and their license as resources. DirectWrite loads them into a private in-memory font collection; they are not installed into Windows. Tests use the same embedded resources and verify both real weights, avoiding silent fallback to a system font.
